# سایت شرکت تعاونی عشایری کوه نور دهدشت — نسخه v6

نسخه تستی مناسب GitHub Pages.

## هویت سایت
- نام: شرکت تعاونی عشایری کوه نور دهدشت
- دامنه نهایی: `tavonikohenor.ir`
- دامنه در `config.js` ثبت شده، اما تا زمان خرید/اتصال دامنه هیچ Redirect اجباری وجود ندارد.
- برای GitHub Pages فعلاً نیازی به فایل `CNAME` نیست؛ پس از آماده شدن DNS آن را اضافه می‌کنیم.

## امکانات فعلی
- هدر روشن با دو لوگو و عنوان نستعلیق
- بخش «آخرین اخبار»
- اسلایدر افقی اخبار با دکمه‌های چپ/راست
- آرشیو «همه اخبار» و ورود به متن کامل هر خبر
- بخش «گزارش تصویری» به صورت افقی
- باز کردن عکس و حرکت چپ/راست بین تصاویر
- حذف شماره‌های ۰۱، ۰۲، ۰۳ و ۰۴
- «عشایر؛ سرمایه ملّی» و «چگونگی تعاونی» به صورت مطالب کامل در پنجره جداگانه
- «اسناد و مدارک»
- «درباره ما»
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## فایل‌ها
- `index.html` رابط اصلی
- `style.css` طراحی و واکنش‌گرایی
- `script.js` اخبار، گالری و محتوای سایت
- `config.js` تنظیمات سایت، دامنه و ایمیل مالک
- `README.md` راهنمای پروژه

## مرحله بعد
Supabase برای:
1. ورود مالک با ایمیل تعیین‌شده
2. پنل مدیریت
3. ثبت/ویرایش/حذف اخبار
4. آپلود دائمی تصاویر در Supabase Storage
5. مدیریت مطالب ثابت
6. اعمال دسترسی فقط برای مالک/مدیران مجاز

> تصاویر این نسخه هنوز از لینک‌های فعلی uupload.ir خوانده می‌شوند. برای نسخه نهایی، تصاویر را به Supabase Storage منتقل می‌کنیم تا وابستگی به سرویس آپلود فعلی حذف شود.
