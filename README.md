# پایگاه اطلاع‌رسانی شرکت تعاونی عشایری کوه نور کهگیلویه

نسخه آزمایشی استاتیک برای انتشار روی GitHub Pages.

## انتشار روی GitHub Pages

1. فایل‌های `index.html`، `style.css` و `script.js` را در ریشه repository قرار دهید.
2. در GitHub به `Settings → Pages` بروید.
3. در بخش `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
4. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کنید.
5. چند لحظه بعد آدرس GitHub Pages فعال می‌شود.

## نکات نسخه فعلی

- عنوان هدر با فونت نستعلیق نمایش داده می‌شود.
- اعداد ۰۱ تا ۰۴ از منوی اصلی حذف شده‌اند.
- دکمه‌های بعدی/قبلی اخبار و نقاط پیمایش قابل کلیک هستند و در موبایل نیز نمایش داده می‌شوند.
- خبرها شامل دو خبر واقعی ارائه‌شده و تصاویر مربوط به هر خبر هستند.
- کلیک روی خبر، متن کامل و گالری تصاویر همان خبر را باز می‌کند.
- سه سند رسمی در بخش «اسناد و مدارک» قرار دارند.
- برای اجرای نسخه فعلی هیچ Backend یا دامنه‌ای لازم نیست.
