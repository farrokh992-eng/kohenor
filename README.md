# سایت شرکت تعاونی عشایری کوه نور کهگیلویه

نسخه استاتیک اولیه برای تست روی GitHub Pages.

## انتشار روی GitHub Pages

1. یک Repository جدید در GitHub بسازید.
2. فایل‌های `index.html`، `style.css` و `script.js` را در ریشه Repository قرار دهید.
3. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید.
4. Branch را روی `main` و Folder را روی `/ (root)` بگذارید.
5. Save کنید.

پس از انتشار، بعداً دامنه `taavonikohenor.ir` را به همین GitHub Pages متصل می‌کنیم.

## ویرایش اخبار

اخبار نمونه داخل `script.js` و آرایه `news` قرار دارند. عنوان، تاریخ، خلاصه و متن کامل هر خبر را می‌توان همان‌جا تغییر داد.

## ویرایش اسناد

آدرس سه سند در آرایه `docs` در `script.js` قرار دارد.
